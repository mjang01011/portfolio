This blog post is my summary of the paper **"Autoregressive Model Beats Diffusion: Llama for Scalable Image Generation"**.
Can a vanilla autoregressive model like Llama, without inductive biases on visual signals (treating an image as a sequence of tokens), achieve SOTA image generation performance?
**Achievements:**
1) Image tokenizer with downsample ratio of 16, reconstruction FID (rFID) 0.94, codebook usage 97%. - Downsample ratio of 8 is competitive with or better than continuous VAEs -> discrete representation in tokenizers is no longer the bottleneck for image reconstruction. *(Note: Historically, Autoregressive models required images to be converted into discrete tokens (integers from a fixed codebook). Diffusion models, however, typically use continuous latent representations (floating-point vectors), which generally preserved much more visual detail. The "bottleneck" was the belief that squeezing an image into a limited set of discrete codes inherently lost too much information, preventing AR models from ever matching the reconstruction quality of Diffusion-based VAEs.)*
2) **C2I (Class-to-Image):** Models ranging from 111M to 3.1B parameters achieved 2.18 FID on ImageNet 256x256.
3) **T2I (Text-to-Image):** 775M parameter model utilizing two-stage training: 1) LAION-COCO, 2) high aesthetics quality images.
4) **Inference:** LLM serving frameworks allow them to achieve a 326% - 414% inference speedup.
**TL;DR:** Vanilla autoregressive models that apply the exactly same “next-token prediction” as language models are also able to achieve state-of-the-art image generation performance.

### MODEL DETAILS
#### Overview
Image pixels $x\in\mathbb{R}^{H\times W\times 3}$ are quantized into $q\in\mathbb{Q}^{h\times w}$ discrete tokens by the image tokenizer. Here, $h = H/p$ and $w = W/p$, where $p$ is the downsample ratio, and $q^{(i,j)}$ represents the indices of the image codebook.
These image tokens are then reshaped into a sequence of $h\cdot w$ tokens in raster scan ordering. For image generation, the image tokens $(q_1, q_2, ..., q_{h\cdot w})$ are generated by autoregressive models using next-token prediction. Finally, these image tokens are converted back to image pixels by the image tokenizer decoder.
---
#### Image Tokenizer
##### Architecture
A Quantized-Autoencoder (VQGAN encoder-quantizer-decoder) is used. The encoder and the decoder are ConvNets with downsample ratio $p$.
The quantizer contains a codebook $Z\in\mathbb{R}^{K\times C}$ with $K$ learnable vectors of dimension $C$. The encoder projects image pixels to a feature map $f$. The quantization process maps each vector $f^{(i,j)}$ in the feature map to the code index $q^{(i,j)}$ of its nearest vector $z^{(i,j)}$ in the codebook.
During decoding, the code index $q^{(i,j)}$ is remapped to the feature vector $z^{(i,j)}$, and the decoder converts these feature vectors back into image pixels $\hat{x}$.
Applying $l_2$-normalization to codebook vectors, using a low vector dimension $C$, and a large codebook size $K$ significantly improves reconstruction quality and codebook usage.
##### Training Loss
Since quantization is non-differentiable, a straight-through gradient estimator is used to preserve the gradient from the decoder to the encoder:
$$
z = sg[z - f] + f
$$
(where $sg[\cdot]$ is a stop-gradient operation).
For codebook learning:
$$
\mathcal{L}_{VQ} = ||sg[f] - z||_2^2 + \beta||f - sg[z]||_2^2
$$
The second term is the commitment loss used to force feature vectors extracted from the encoder to be close to the codebook vectors, where $\beta$ is the commitment loss weight.
For image reconstruction training:
$$
\mathcal{L}_{AE} = l_2(x, \hat{x}) + \mathcal{L}_P(x, \hat{x}) + \lambda_G\mathcal{L}_G(\hat{x})
$$
Here, $l_2$ is a reconstruction loss on image pixels, $\mathcal{L}_P(\cdot)$ is a perceptual loss from LPIPS, $\mathcal{L}_G(\cdot)$ is an adversarial loss from a PatchGAN discriminator trained simultaneously, and $\lambda_G$ is the adversarial loss weight.

## Image Generation by Autoregressive Models
### 1. Llama Architecture
Largely based on the original Llama architecture, utilizing pre-normalization with RMSNorm, SwiGLU activations, and 2D RoPE. AdaLN is deliberately excluded to maintain structural consistency with standard LLMs.
### 2. C2I (Class-to-Image)
A class embedding is indexed from a set of learnable embeddings and serves as the prefilling token embedding. Starting from this prefilled token, the model generates the sequence of image tokens via next-token prediction. Generation stops when it reaches the pre-defined maximum length location.
### 3. T2I (Text-to-Image)
FLAN-T5 XL is used for text encoder, and an additional MLP is used to project encoded text features, which are then used as prefilling token embedding (text vectors and push them into Llama's context window as the initial starting state) in AR models.
### 4. Classifier-Free Guidance (CFG)
The conditional is randomly dropped and replaced by a null unconditional embedding. For each token, the final logit $lg$ is calculated using the conditional logit $lc$, the unconditional logit $lu$, and the guidance scale $s$:
$$
lg = lu + s(lc - lu)
$$
---
### Training Details
80GB A100 GPUs for large models. Smaller models (<1.4B parameters) utilize DDP (Distributed Data Parallel) to divide the dataset across multiple GPUs for parallel processing.

| **Adversarial Loss Weight** | 0.5 (Enabled after 20k training iterations) |
#### Evaluation Metrics
* **r-FID:** Measured on the 256x256 50k ImageNet validation set.
* **Codebook Usage:** Calculated as the percentage of used codes in a queue of size 65536 relative to the entire codebook size.
* **Reconstruction Quality:** Measured using PSNR and SSIM.
#### Results
* **Vector Dimension:** Reducing the codebook vector dimension from 256 to 32, and then to 8, consistently achieves much better reconstruction quality and codebook usage.
* **Downsample Ratio:**
  * A ratio of 16 (yielding an image with only 256 tokens, or 16x16) is insufficient for good reconstruction quality.
  * Increasing the number of tokens to 576 (24x24) massively improves image quality, dropping the r-FID from 2.43 to 0.99.
Here, a key finding is proposed:
The discrete representation in the image tokenizer is no longer the bottleneck for image reconstruction. This tokenizer is highly competitive with continuous latent space representations, such as the SD VAE, SDXL VAE, and OpenAI's Consistency Decoder.
